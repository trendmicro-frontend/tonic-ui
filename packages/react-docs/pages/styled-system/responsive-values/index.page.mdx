# Responsive values

Responsive values use the [breakpoints](../../theme/breakpoints) defined in the theme. Each breakpoint starts at its minimum viewport width.

| Breakpoint | Minimum width | At 16px |
| :--------- | :------------ | :------ |
| `sm` | `40rem` | `640px` |
| `md` | `48rem` | `768px` |
| `lg` | `64rem` | `1024px` |
| `xl` | `80rem` | `1280px` |
| `2xl` | `96rem` | `1536px` |

Pixel equivalents assume the browser's default initial font size of `16px`.

Use either array or object syntax for responsive style props.

## Array syntax

Array values are base-first. Index `0` is an unconditional base value, and subsequent indices correspond to the configured breakpoint keys in ascending width order. With the default theme, the indices after the base are `sm`, `md`, `lg`, `xl`, and `2xl`.

For example, start with a `Box` that has a fixed width:

```jsx
<Box backgroundColor="red.500" width="50%">
  This is a box
</Box>
```

Use an array to change the width across breakpoints:

```jsx
<Box backgroundColor="red.500" width={['25%', '50%', '75%', '100%', null, '100%']}>
  This is a box
</Box>
```

The values apply as follows:

| Index | Breakpoint | Width |
| :---- | :--------- | :---- |
| `0` | Base | `25%` |
| `1` | `sm` (`≥ 40rem`) | `50%` |
| `2` | `md` (`≥ 48rem`) | `75%` |
| `3` | `lg` (`≥ 64rem`) | `100%` |
| `4` | `xl` (`≥ 80rem`) | No value (`null`) |
| `5` | `2xl` (`≥ 96rem`) | `100%` |

Pass `null` to skip a position. A skipped position retains the last applicable value.

### Migrating array values

The previous breakpoint scale included `xs` at `0px` after the unconditional base. Remove that slot and move its value to the base if it was set: `xs` matched every nonnegative viewport width. The remaining named slots shift left by one. Use a named style prop to make the intended breakpoint explicit:

```jsx
// Before: xs applied everywhere, and index 4 was lg.
<Text fontSize={['4xl', '3xl', null, null, 48]} />

// After: the large size starts at lg (64rem).
<Text fontSize={{ _: '3xl', lg: 48 }} />
```

## Object syntax

Named keys make the intended breakpoints explicit. Use `_` for the unconditional base value. For example, start with a `Text` component with a fixed font size:

```jsx
<Text fontSize={32}>
  This is a text
</Text>
```

Use an object to change the font size across breakpoints:

```jsx
<Text fontSize={{ _: 24, md: 32, lg: 40, xl: 48 }}>
  This is a text
</Text>
```

The base font size is `24px`. At `md` (`≥ 48rem`) it becomes `32px`, at `lg` (`≥ 64rem`) it becomes `40px`, and at `xl` (`≥ 80rem`) it becomes `48px`.

Keep named breakpoint objects on flat style props. Inside `sx`, use an array or [breakpoint media queries](../../theme/breakpoints#css-media-queries). A value such as `sx={{ gap: { sm: '4x' } }}` does not set a responsive gap.

## Under the hood

Given the following example:

```jsx
<Box width={{ _: '100%', sm: '50%', md: '25%' }}>
  This is a box
</Box>
```

The responsive style props generate the following CSS:

```css
.Box {
  width: 100%;
}

@media (width >= 40rem) {
  .Box {
    width: 50%;
  }
}

@media (width >= 48rem) {
  .Box {
    width: 25%;
  }
}
```
