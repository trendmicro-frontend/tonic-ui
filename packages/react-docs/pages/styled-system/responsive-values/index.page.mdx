# Responsive values

Responsive values use the [breakpoints](../../theme/breakpoints) defined in the theme. Each breakpoint starts at its minimum viewport width.

| Breakpoint | Minimum width |
| :--------- | :------------ |
| `xs` | `0px` |
| `sm` | `600px` |
| `md` | `900px` |
| `lg` | `1200px` |
| `xl` | `1536px` |

Use either array or object syntax for responsive style props.

## Array syntax

Array values are base-first. Index `0` is an unconditional base value, and subsequent indices correspond to the configured breakpoint keys in ascending width order. With the default theme, the indices after the base are `xs`, `sm`, `md`, `lg`, and `xl`.

For example, start with a `Box` that has a fixed width:

```jsx
<Box backgroundColor="red.500" width="50%">
  This is a box
</Box>
```

Use an array to change the width across breakpoints:

```jsx
<Box backgroundColor="red.500" width={[null, '25%', '50%', '75%', '100%', '100%']}>
  This is a box
</Box>
```

The values apply as follows:

| Index | Breakpoint | Width |
| :---- | :--------- | :---- |
| `0` | Base | No value (`null`) |
| `1` | `xs` (`≥ 0px`) | `25%` |
| `2` | `sm` (`≥ 600px`) | `50%` |
| `3` | `md` (`≥ 900px`) | `75%` |
| `4` | `lg` (`≥ 1200px`) | `100%` |
| `5` | `xl` (`≥ 1536px`) | `100%` |

Pass `null` to skip a position. Since `xs` starts at `0px`, a value at index `1` overrides the unconditional base at every nonnegative viewport width.

### Migrating array values

Index `3` previously corresponded to `lg`. With the new breakpoint scale, index `3` corresponds to `md`, while `lg` is at index `4`. Tonic UI keeps index `0` as the unconditional base, unlike Material UI's `iterateBreakpoints`. To preserve a large-screen change at `lg`, use a named style prop:

```jsx
// Before: index 3 was lg.
<Text fontSize={['4xl', null, null, 48]} />

// After: the large size starts at lg (1200px).
<Text fontSize={{ _: '4xl', lg: 48 }} />
```

## Object syntax

Named keys make the intended breakpoints explicit. Use `_` for the unconditional base value. For example, start with a `Text` component with a fixed font size:

```jsx
<Text fontSize={32}>
  This is a text
</Text>
```

Use an object to change the font size across breakpoints:

```jsx
<Text fontSize={{ _: 24, md: 32, lg: 40, xl: 48 }}>
  This is a text
</Text>
```

The base font size is `24px`. At `md` (`≥ 900px`) it becomes `32px`, at `lg` (`≥ 1200px`) it becomes `40px`, and at `xl` (`≥ 1536px`) it becomes `48px`.

Keep named breakpoint objects on flat style props. Inside `sx`, use an array or [breakpoint media queries](../../theme/breakpoints#css-media-queries). A value such as `sx={{ gap: { sm: '4x' } }}` does not set a responsive gap.

## Under the hood

Given the following example:

```jsx
<Box width={{ _: '100%', sm: '50%', md: '25%' }}>
  This is a box
</Box>
```

The responsive style props generate the following CSS:

```css
.Box {
  width: 100%;
}

@media (width >= 600px) {
  .Box {
    width: 50%;
  }
}

@media (width >= 900px) {
  .Box {
    width: 25%;
  }
}
```
