# Responsive values

Responsive values use the [breakpoints](../../theme/design-tokens/breakpoints) defined in the theme. Each breakpoint starts at its minimum viewport width.

| Breakpoint | Minimum width | At 16px |
| :--------- | :------------ | :------ |
| `xs` | <Code>{formatBreakpoint(breakpoints, 'xs')}</Code> | <Code>{formatBreakpoint(breakpoints, 'xs', 'px')}</Code> |
| `sm` | <Code>{formatBreakpoint(breakpoints, 'sm')}</Code> | <Code>{formatBreakpoint(breakpoints, 'sm', 'px')}</Code> |
| `md` | <Code>{formatBreakpoint(breakpoints, 'md')}</Code> | <Code>{formatBreakpoint(breakpoints, 'md', 'px')}</Code> |
| `lg` | <Code>{formatBreakpoint(breakpoints, 'lg')}</Code> | <Code>{formatBreakpoint(breakpoints, 'lg', 'px')}</Code> |
| `xl` | <Code>{formatBreakpoint(breakpoints, 'xl')}</Code> | <Code>{formatBreakpoint(breakpoints, 'xl', 'px')}</Code> |
| `2xl` | <Code>{formatBreakpoint(breakpoints, '2xl')}</Code> | <Code>{formatBreakpoint(breakpoints, '2xl', 'px')}</Code> |

Pixel equivalents assume the browser's default initial font size of `16px`.

Use a breakpoint object on a flat style prop or in `sx` or `__sx`. Responsive value arrays are no longer supported in style props or in individual `sx` or `__sx` declarations.

## Breakpoint object syntax

Named keys make the intended breakpoints explicit. Use `_` for an unconditional base value:

```jsx
<Text fontSize={{ _: 24, md: 32, lg: 40, xl: 48 }}>
  This is a text
</Text>
```

The base font size is `24px`. At `md` (<Code>{`≥ ${formatBreakpoint(breakpoints, 'md')}`}</Code>) it becomes `32px`, at `lg` (<Code>{`≥ ${formatBreakpoint(breakpoints, 'lg')}`}</Code>) it becomes `40px`, and at `xl` (<Code>{`≥ ${formatBreakpoint(breakpoints, 'xl')}`}</Code>) it becomes `48px`. A value continues to apply until another matching breakpoint overrides it. Omit `_` if no base declaration is needed. Unconfigured breakpoint names are ignored.

## Responsive styles in `sx`

Use the same breakpoint object in `sx` or the internal `__sx` channel:

```jsx
<Box sx={{ width: { _: '100%', md: '50%' } }} />
```

`base` is an alias for `_` in these channels. For a bounded range or other explicit media condition, use a query key. In a child of `TonicProvider`, use the active theme's helpers:

```jsx
import { Box, useTheme } from '@tonic-ui/react';

function ResponsiveBox() {
  const { breakpoints } = useTheme();

  return (
    <Box sx={{ width: '100%', [breakpoints.gte('md')]: { width: '50%' } }} />
  );
}
```

You can also use a native `@media` key. Breakpoint objects use viewport widths. For container widths, use an explicit `@container` key, written as native CSS or generated by `theme.containerQueries`. See [media queries](../../theme/media-queries#css-media-queries) and [container queries](../../theme/container-queries).

Arrays passed to `sx` itself, or to the internal `__sx` channel, still compose style objects in order. They are not responsive value arrays:

```jsx
<Box sx={[{ color: 'black' }, { '&:hover': { color: 'blue' } }]} />
```

## Migrating removed responsive arrays

Map each old array position using the breakpoint scale configured in the old theme, then use named keys in flat props, `sx`, or `__sx`. For example, an earlier scale placed `xs` at `0px` after the unconditional base, so `xs` matched every nonnegative viewport and index `4` was `lg`:

```jsx
// Before: removed array syntax with the earlier xs-based scale.
<Text fontSize={['4xl', '3xl', null, null, 48]} />

// After: xs becomes the base, and the large size starts at lg.
<Text fontSize={{ _: '3xl', lg: 48 }} />
```

If the old `xs` slot was empty, retain the original base instead. Recheck the actual viewport thresholds: configured breakpoint widths may have changed along with their names or positions.

## Under the hood

Given the following example:

```jsx
<Box width={{ _: '100%', sm: '50%', md: '25%' }}>
  This is a box
</Box>
```

The responsive style props generate the following CSS:

<CodeBlock language="css" code={`.Box {
  width: 100%;
}

${breakpoints.gte('sm')} {
  .Box {
    width: 50%;
  }
}

${breakpoints.gte('md')} {
  .Box {
    width: 25%;
  }
}
`} />
