# Migrating color tokens from v2 to v3

> The v2 tokens remain fully backward compatible in v3. You can upgrade without changing any token references and migrate at your own pace. V2 and v3 tokens can coexist, enabling incremental adoption.

## Overview

Tonic UI v3 introduces a new token system based on dot notation and semantic tokens that automatically adapt to light and dark modes.

Key benefits:

* **Automatic color mode handling** — no need for manual colorMode switching
* **Semantic meaning** — tokens express intent, not raw color values
* **Improved consistency** — better alignment with the design system

For app setup and breaking API changes, see the [Migrating from Tonic UI v2 to v3](../migrating-from-v2-to-v3) guide first.

## Primitive color tokens

Primitive color tokens have changed from a flat colon-based format (v2) to a nested dot notation format (v3). The numeric scale is also multiplied by 10.

v3:
```jsx

  Content

```

v2:
```jsx
const [colorStyle] = useColorStyle();

<Box
  backgroundColor={colorStyle.background.primary}
  color={colorStyle.color.primary}
>
  <Text color={colorStyle.color.secondary}>
    Secondary content
  </Text>
</Box>
```

v3:
```jsx
<Box
  backgroundColor="background.low"
  color="text.primary"
>
  <Text color="text.secondary">
    Secondary content
  </Text>
</Box>
```

### Text

| Semantic token | Definition |
|:--|:--|
| <ColorPreview value="text.accent" /> `text.accent` | The most prominent neutral text color, used for headings, high-emphasis CTA text, and text in hovered, active, or selected states. |
| <ColorPreview value="text.primary" /> `text.primary` | Standard color for general table text and paragraph text. |
