# Explicit lengths for breakpoint queries

Status: implemented. Numeric `0` is the only unitless number accepted.

## API contract

Keep `theme.breakpoints` and `theme.containerQueries`. On `breakpoints`, unnamed `containerQueries`, and `containerQueries(name)`, `gte`, `lt`, and `between` take a breakpoint name, the number `0`, or a single length string with an explicit unit. Emit `0` unchanged as CSS zero length; reject the string `'0'` and any nonzero number. `only` takes a configured name only. Do not add an implicit unit or a `{ value, unit }` alternative. Do not change `createTheme({ breakpoints: { values, unit } })`, its default scale, or the handling of the unit for named breakpoints.

- In `packages/utils/src/internal/createBreakpoints.js`, define `QueryLength` as the JSDoc template literal type `${number}${'px' | 'rem' | 'em'}` and use `Breakpoint | QueryLength | 0` for each of the three helpers' boundaries. TypeScript approximates the syntax; runtime enforces it. Match explicit strings with `^(?:[0-9]+(?:\.[0-9]+)?|\.[0-9]+)(?:px|rem|em)$` and reject magnitudes whose numeric portion is not finite. Keep the original valid string, including its unit. Zero and fractional lengths are valid. Reject signs, whitespace, unsupported units, scientific notation, functions, and whole CSS conditions.
- Resolve a configured name to `${value}${themeUnit}`. Treat `2xl` and strings matching `^[A-Za-z][A-Za-z0-9-]*$` as breakpoint names. An unconfigured name throws the existing `RangeError('[Tonic UI] Unknown breakpoint: …')`, including `xs`, `mobile`, and `2xl` on a sparse scale. Invalid input shapes and non-name strings that fail the length rules throw `TypeError`. For `only`, use the same name lookup; non-name inputs, including `0`, throw `TypeError('[Tonic UI] Expected a breakpoint name.')`.
- `gte` includes the lower bound; `lt` excludes the upper bound; `between(start, end)` is `[start, end)`. Resolve the two endpoints independently, retaining mixed units and order. Do not convert or compare the endpoints in JavaScript. `only` spans from the named breakpoint to the next configured one and has no upper bound for the last key.
- `packages/utils/src/internal/createContainerQueries.js` delegates to the same helpers and derives its types from them, preserving the named and unnamed call forms. CSS itself resolves relative units: `em` in `@media` uses the browser's initial font size; `em` in a size `@container` query uses the query container's computed font size. Explicit unit strings are not a guarantee of equivalent behavior across query contexts.

## Named zero breakpoint

The default v3 scale starts at `xs: 0`. The `xs` name can be overridden or omitted like other keys. Numeric `0` remains valid for `gte`, `lt`, and `between`, independently of that setting. The Breakpoints guide includes copyable default `rem` and equivalent `px` examples; Chromium checks both against the current theme at a `16px` initial font size.
